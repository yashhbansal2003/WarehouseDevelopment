# Warehouse Development Company — Bangalore

**Promise:** From your land to a leased warehouse — one team, one contract, a fixed timeline.

We are an end-to-end warehouse development company for 50,000–3,00,000 sq ft projects on the Hoskote, Nelamangala–Dabaspete and Doddaballapur belts. We take landowners from bare land to a leased, financed, operating asset. Our flagship and proof asset is **Project 001: Hoskote** (1,13,000 sq ft PEB).

## How to use the playbook

1. Read [`playbook/00-strategy.md`](playbook/00-strategy.md) once, end to end. It explains *why* every later step exists.
2. Lock the brand ([`01-brand.md`](playbook/01-brand.md)) in week 1, because the website, ads and brochure all depend on it.
3. From then on, run the business off the calendar ([`10-12-month-calendar.md`](playbook/10-12-month-calendar.md)) and the weekly rhythm in it.
4. Every month, do the matching module in the learning path ([`13-learning-path.md`](playbook/13-learning-path.md)), so you learn each skill in the same week you use it.
